# Unichest Large

Enlarges the [Unichest](https://github.com/mpcomplete/factorio-unichest) chest to a **7x7 logistics dock**.

## Why so big?

Balance through geometry: the 7x7 footprint makes the chest ideal subfactory
infrastructure — a proper I/O port for train stations and subfactory boundaries —
but too large to direct-insert from every assembler. Big enough to matter, too
big to spam.

## Install

Requires the **Unichest** mod (declared as a dependency, so the Factorio mod
portal downloads it automatically). This mod loads after Unichest and modifies
its chest entity in place; it adds no new items or recipes of its own.
